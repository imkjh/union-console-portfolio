자동 테스트에는 예시 응답과 테스트 데이터를 사용했습니다. 한 모델의 실패가 다른 모델에 영향을 주지 않는지, 재시도할 때 이미 받은 답변이 유지되는지를 확인했습니다.

## 실제 모델 호출과 시연

개발 환경에서 Codex CLI의 GPT, Antigravity CLI의 Gemini·Claude 응답을 확인했습니다. 기존 구독과 CLI 인증을 사용했으며, 별도 API 키로 직접 모델을 호출하는 경로는 사용하지 않았습니다.

[대표 영상 · 35초](media/live-comparison.mp4)은 가상의 고객지원 질문을 한 번 입력해 GPT·Gemini의 실행 상태와 답변을 확인하는 장면입니다. 두 모델 모두 첫 시도에 완료됐습니다. 응답 수정이나 대기 시간 생략은 없으며, 공개용 영상은 웹 화면만 담았습니다. GitHub에서 이미지 표시와 MP4 재생도 확인했습니다.

## 검증의 한계

- 실제 서비스 장애나 시간 초과 후의 복구를 촬영하지는 않았습니다. 재시도 동작은 Demo와 자동 테스트로 검증했습니다.
- 기존 개발 환경의 의존성을 재사용했습니다. 새 PC의 최초 설치와 실제 모델 재연결은 미검증입니다.
- 장기 사용 안정성이나 시간 절감 효과는 측정하지 않았습니다.
- 호출에는 기존 구독의 사용량이 소모됩니다. API 방식 대비 절감액이나 손익분기점은 측정하지 않았습니다.
